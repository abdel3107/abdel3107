# Profile README — one-time setup

The README shows GitHub **stats**, **top-languages**, and **trophy** cards. Those
cards are served by two small apps. The free *shared* public servers for them are
permanently rate-limited by GitHub and often show up as broken images, so this
profile points at **your own** copies on Vercel instead. You deploy each once
(~10 minutes total) and they load reliably forever after.

You also run the **snake animation** workflow once.

---

## 0. Create a GitHub token (used by both deploys)

1. Go to **https://github.com/settings/tokens** → **Generate new token (classic)**.
2. Name it e.g. `readme-cards`, set no expiration (or a long one).
3. Tick the **`repo`** scope (needed so private-contribution counts work).
4. **Generate** and copy the token (starts with `ghp_…`). Keep it somewhere safe —
   you'll paste it into Vercel twice below.

---

## 1. Stats + Top-languages  →  `grs-abdel3107.vercel.app`

*One deploy powers both the "GitHub stats" and "Top languages" cards.*

1. Fork **https://github.com/anuraghazra/github-readme-stats** to your account.
2. Go to **https://vercel.com** and sign in with GitHub.
3. **Add New… → Project → Import** your fork of `github-readme-stats`.
4. Before deploying, set the **Project Name** to exactly:

   ```
   grs-abdel3107
   ```

   (This makes the URL `https://grs-abdel3107.vercel.app`, which is what the README
   already uses.)
5. Open **Environment Variables** and add:

   | Name    | Value                    |
   | ------- | ------------------------ |
   | `PAT_1` | *your `ghp_…` token*     |

6. Click **Deploy**. When it finishes, open
   `https://grs-abdel3107.vercel.app/api?username=abdel3107` in your browser — you
   should see your stats card render.

---

## 2. Trophies  →  `trophy-abdel3107.vercel.app`

*Optional — skip this if you don't want the trophy row; just tell me and I'll remove
that card from the README.*

1. Fork **https://github.com/ryo-ma/github-profile-trophy** to your account.
2. In Vercel: **Add New… → Project → Import** your fork.
3. Set the **Project Name** to exactly:

   ```
   trophy-abdel3107
   ```

4. Add an **Environment Variable**:

   | Name           | Value                |
   | -------------- | -------------------- |
   | `GITHUB_TOKEN` | *your `ghp_…` token* |

5. **Deploy**, then check `https://trophy-abdel3107.vercel.app/?username=abdel3107`.

---

## 3. Snake contribution animation

The snake image is generated by a GitHub Action already in this repo
(`.github/workflows/snake.yml`) and won't appear until it runs once.

1. On this repo, open the **Actions** tab → enable workflows if prompted.
2. Select **"Generate Snake Animation"** → **Run workflow**.
3. It creates an `output` branch with the snake SVGs; the README picks them up
   automatically. After that it refreshes on its own every 12 hours.

---

### If you used different Vercel project names
The README expects `grs-abdel3107` and `trophy-abdel3107`. If Vercel gave you
different URLs, just send them over and they'll be patched into the README.
